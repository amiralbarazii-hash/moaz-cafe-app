# تطبيق الدكان (أندرويد)

تطبيق للموظفين: تسجيل المبيعات والتحصيل والمشتريات والمصروفات، مع حسابات الزبائن على الحساب.
المالك يشوف كل شي ويصدّر تقرير إكسل. الموظف يشوف بس سجلاته.

## 1. إعداد Firebase (مرة وحدة)

1. ادخل على https://console.firebase.google.com وأنشئ مشروع جديد.
2. Build → **Authentication** → Get started → فعّل **Email/Password**.
3. Build → **Firestore Database** → Create database → (Production mode).
4. بتبويب **Rules** في Firestore الصق محتوى ملف `firestore.rules` واضغط Publish.
5. Project settings → Add app → Android. اكتب package name: `com.example.cafe`
   (أو غيّره بـ `app/build.gradle.kts` وهون بنفس الوقت).
6. نزّل ملف **google-services.json** وحطّو داخل مجلد `app/`.

## 2. إنشاء الحسابات

- **حساب المالك**: Authentication → Users → Add user. حدد الإيميل وكلمة السر بنفسك.
  بعدين سجّل دخول مرة من التطبيق (بيتسجل كموظف تلقائياً)، وبعدين بـ Firestore
  افتح المجموعة `users` → الوثيقة تبعك → غيّر `role` من `employee` إلى `owner`.
- **حساب كل موظف**: نفس الطريقة (Add user) بإيميل وكلمة سر تحددهم انت.
  ما في تسجيل حساب جديد من التطبيق، فالحسابات كلها عندك.

## 3. بناء الـ APK

1. افتح مجلد `cafe-app` ب **Android Studio** (Hedgehog أو أحدث).
2. انتظر لين يخلص Gradle Sync.
3. من القائمة: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. الملف بيطلع بـ: `app/build/outputs/apk/debug/app-debug.apk`
5. انقلو على التلفون وثبّتو (لازم تسمح بالتثبيت من مصادر غير معروفة).

## 4. أول استخدام

- سجّل دخول بحساب المالك → تبويب **التقارير** → اضغط **تحميل قائمة الأسعار والزبائن**
  (هاد بيحط الأصناف والأسعار والزبائن من ملف الإكسل).
- بعدين الموظفين بيشتغلوا من تبويب **المبيعات / المشتريات / المصروفات**.

## ملاحظات

- التاريخ بيكون وقت التسجيل تلقائياً. ما في تسجيل بتاريخ سابق لسا.
- رصيد الزبون بالتبويب بيحسب من المبيعات اللي بتشوفها: المالك كل المبيعات، والموظف مبيعاتو بس.
- التقرير الإكسل فيه: الملخص اليومي، المبيعات، المشتريات، المصروفات، وأرصدة الزبائن.
- الـ APK من نوع debug، مناسب للتجربة وتثبيت مباشر. للنشر على Play Store لازم توقيع (signing) إصدار.
